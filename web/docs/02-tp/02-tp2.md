# Travail 2 - Interface graphique 🎨

:::note Général

<Row>

<Column>

## Objectif

Implémenter l'interface graphique de votre application en Flutter, **sans back-end**.
Les données peuvent être codées en dur ou stockées en mémoire.


## Utilisation de l'IA

Dans ce TP, l'utilisation de l'IA est possible dans les cas suivants :
- produire la locale en anglais, à partir de celle en français : "complète le fichier pour l'anglais en traduisant les textes en français"
- générer de fausses données pour votre interface graphique (par exemple, une longue liste pour un écran d'accueil, etc.).

Pour le reste de votre code, l'IA est interdite. Vous devez pouvoir expliquer ce que produit votre code, comment il fonctionne. Comme il s'agit 
d'un manquement aux règles sur le plagiat, la note de 0 pourra être appliquée.

## Navigation

&#8203;<Highlight color="tip">3 points</Highlight> L'application comporte plusieurs écrans reliés par une navigation fonctionnelle.

- Au minimum **4 écrans** différents correspondant à vos wireframes du TP1
- La navigation entre les écrans fonctionne (push / pop)
- Un mécanisme de navigation principale est présent (Drawer, BottomNavigationBar ou équivalent)

</Column>

<Column>

## Écrans et composants

&#8203;<Highlight color="tip">8 points</Highlight> Les écrans sont implémentés avec soin.

- Chaque écran correspond à un wireframe de votre TP1
- Les éléments graphiques sont présents et bien disposés
- Les listes (si présentes) utilisent un `ListView.builder`
- La mise en page est cohérente (pas de débordement)

</Column>

## Multilingue

&#8203;<Highlight color="tip">2 points</Highlight> L'application supporte le **français** et l'**anglais**.

- Toutes les chaînes de texte visibles par l'utilisateur sont externalisées dans les fichiers ARB
- Le changement de langue fonctionne (s'adapte à la langue du téléphone ou via un sélecteur)

</Column>

<Column>

## Image Picker 

&#8203;<Highlight color="tip">2 points </Highlight> Votre application permet la sélection d'images par l'utilisateur :

- L'utilisateur peut sélectionner une image depuis la galerie du téléphone
- L'image est affichée dans l'application

L'Image Picker se retrouve dans le récit utilisateur d'ajout d'une photo au profil de l'utilisateur.

</Column>

## Fonctionnement global

&#8203;<Highlight color="danger">4 points négatifs</Highlight> Votre application doit fonctionner sans plantage et correctement.
Ce pointage fonctionne en négatif.

- Plantage de l'application → **-1 point**
- Interface illisible ou débordements → **-1 point**
- Navigation brisée → **-1 point**
- Autre cas problématique → **-1 point**
