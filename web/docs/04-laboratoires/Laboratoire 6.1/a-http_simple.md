# 🌐 6.1A – http_simple

## Objectif 🎯

Effectuer une requête GET avec DIO et afficher le résultat dans une application Flutter.

## À faire 🛠️

1. Créez un projet Flutter nommé `http_simple`.
2. Ajoutez la dépendance `dio` avec `flutter pub add dio`.
3. Ajoutez un champ texte pour entrer un nombre et un bouton pour envoyer la requête.
4. Au clic, appelez `https://fourn6-mobile-prof.onrender.com/exos/long/double/4`, en remplaçant `4` par le nombre entré.
5. Affichez le double retourné dans l'interface, par exemple dans un `Text` ou un `SnackBar`.
6. Affichez aussi un indicateur de chargement durant l'appel et un message compréhensible lorsqu'une erreur réseau survient.

Consultez la recette [DIO 1 - Requête GET de base](../../03-recettes/dio-01-base.md) avant de commencer.
