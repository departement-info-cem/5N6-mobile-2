# Notifications 🚨

:::tip Avant la séance :

Consultez la recette sur les [Notifications 🚨](../03-recettes/notifications.md).

Consultez l'exemple de code sur les [Cloud Functions](https://github.com/departement-info-cem/5N6-mobile-2/releases/latest/download/code-demo_cloud_functions.zip), en particulier la démo **Notifications**. Puisque Cloud Messaging n'a pas d'émulateur, cette démo a besoin d'un vrai projet Firebase : la section [Le mot de la fin](../03-recettes/notifications.md#le-mot-de-la-fin) de la recette explique comment l'essayer.

:::

:::info Séance :
Nous verrons comment un serveur envoie une notification à un appareil précis avec Firebase Cloud Messaging, et comment l'application la reçoit, qu'elle soit au premier plan, en arrière-plan ou fermée.
:::

:::note Exercices
Implémentez les notifications push dans votre travail pratique, si c'est une fonctionnalité prévue dans votre projet.
:::
