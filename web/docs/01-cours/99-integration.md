# Intégration

:::tip Intégration

Pendant les séances d'intégration, il n'y a pas de nouveau contenu. C'est du temps prévu pour travailler sur vos projets. Vous pouvez poser des questions, résoudre des problèmes et approfondir vos connaissances.

Le but est de consolider ce que vous avez vu dans les séances précédentes.

Vous pouvez vous familiariser avec les différents Widgets Flutter en cherchant les [**widget of the week**](https://www.youtube.com/playlist?list=PLjxrf2q8roU23XGwz3Km7sQZFTdB996iG) :

- Container
- Row
- Column
- Expanded
- Text
- SizedBox
- etc.

:::

:::info Travail à faire

Vous pouvez compléter les exercices ou essayer de refaire ceux qui vous ont posé problème. C'est une bonne préparation à l'examen où les exercices ont le même format.

Vous devez avancer votre travail en cours et poser des questions si vous êtes actuellement bloqué.

Votre professeur est disponible pour des questions sur tout le contenu vu jusqu'ici.

Vous pouvez prendre de l'avance en regardant le contenu des semaines qui arrivent.

:::
